Технологический стек приложения

    Клиентская часть: Мобильное клиентское приложение, разрабатываемое на языке Dart с использованием фреймворка Flutter.

    Серверная часть: REST API, разрабатываемое на языке Python с использованием веб-фреймворка FastAPI.

    База данных: Реляционная СУБД MySQL.

1. Перечень и функционал экранов интерфейса (UI Screens)

Весь функционал мобильного приложения группируется по следующим экранам, разделенным на общие экраны, интерфейс Слушателя и интерфейс Администратора.
1.1. Общие экраны (для всех пользователей)

Доступны пользователю до входа в систему для создания учетной записи и последующей авторизации.

    Экран регистрации:

        Интерфейс для ввода учетных данных нового пользователя (логин/email, пароль, подтверждение пароля).

        Кнопка отправки данных для создания учетной записи Слушателя в базе данных MySQL.

    Экран авторизации:

        Интерфейс ввода логина и пароля.

        После успешной проверки учетных данных сервером происходит сохранение полученного JWT-токена на устройстве и перенаправление пользователя на соответствующий его роли экран (Главный экран для Слушателя или Панель администратора).

1.2. Экраны Слушателя

Основная часть интерфейса для конечного пользователя, ориентированная на удобное потребление аудиоконтента.

    Главный экран (Поиск и навигация):

        Поисковая строка для ввода ключевых слов (поиск подкастов по названию).

        Блок фильтрации подкастов по категориям.

        Список доступных подкастов, получаемый в формате JSON от сервера FastAPI, с отображением названия, категории и описания.

    Экран воспроизведения (Bottom Sheet / Сворачиваемая шторка):

        Реализуется в виде интерактивной панели, которая выдвигается снизу главного экрана, не перекрывая его полностью.

        Отображает информацию о текущем воспроизводимом подкасте.

        Содержит элементы управления аудиопотоком: кнопка воспроизведения/паузы, ползунок (slider) для отображения прогресса и перемотки трека, а также отображение времени воспроизведения.

1.3. Экраны Администратора

Интерфейс для управления базой данных, пользователями и медиаконтентом.

    Экран списка пользователей и подкастов:

        Отображение списка всех зарегистрированных в системе пользователей.

        Отображение полного каталога загруженных подкастов.

        С этого экрана администратор может переходить к действиям по управлению контентом.

    Экран публикации подкаста:

        Форма для ввода метаданных нового подкаста (название, категория, описание).

        Элемент интерфейса для выбора аудиофайла в формате .mp3 с памяти устройства.

        Кнопка отправки формы на сервер FastAPI для создания записи в MySQL и загрузки файла.

    Экран/Интерфейс удаления подкаста:

        Интерфейс (может быть реализован как отдельный экран подтверждения или диалоговое окно), запрашивающий подтверждение на удаление конкретного подкаста по его ID.

        При подтверждении инициирует удаление записи из MySQL и физическое удаление аудиофайла с сервера.

2. Ограничения на ввод информации пользователем
2.1. Экраны регистрации и авторизации

    Логин / Email:

        Обязательное поле, валидация формата (для email) или допустимого набора символов (для логина).

        Ограничение по длине (например, от 3 до 50 символов).

    Пароль:

        Обязательное поле с минимальной длиной (не менее 8 символов) для обеспечения базовой безопасности.

2.2. Экраны Слушателя

    Главный экран (Поле поиска):

        Тип данных: строка.

        Максимальная длина поискового запроса: до 255 символов.

        Санитизация запроса на сервере для защиты от SQL-инъекций.

2.3. Экраны Администратора

    Экран публикации подкаста (Форма ввода):

        Название: обязательное поле, текстовый формат, не должно быть пустым.

        Категория: выбор из предопределенного списка или текстовое поле с ограничением по длине.

    Загрузка файлов:

        Ограничение по размеру: максимальный размер файла ограничен (например, до 100 МБ).

        Формат и валидация: проверка расширения файла на клиенте и сервере (разрешено только .mp3) и MIME-типа (audio/mpeg).
