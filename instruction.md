### Шаг 1: Подготовка и запуск базы данных MySQL

1. Убедитесь, что на вашем компьютере запущен сервер MySQL (локально или в Docker).
2. Подключитесь к MySQL через любой удобный клиент (DBeaver, phpMyAdmin, VS Code Database Client или консоль) и создайте базу данных:
   ```sql
   CREATE DATABASE podcast_db;
   ```
3. Откройте файл бэкенда **`backend/app/database.py`** и отредактируйте строку подключения, указав ваши актуальные данные (пользователь, пароль, хост, порт):
   ```python
   # Пример строки: mysql+pymysql://<ПОЛЬЗОВАТЕЛЬ>:<ПАРОЛЬ>@<ХОСТ>:<ПОРТ>/<ИМЯ_БД>
   DATABASE_URL = "mysql+pymysql://root:password@localhost:3306/podcast_db"
   ```

### Шаг 2: Установка зависимостей и запуск бэкенда (FastAPI)

1. Откройте терминал и перейдите в папку с бэкендом:
   ```bash
   cd backend
   ```
2. Создайте и активируйте виртуальное окружение Python (если не сделали этого ранее):
   * **Windows (PowerShell):**
     ```powershell
     python -m venv venv
     .\venv\Scripts\Activate.ps1
     ```
   * **macOS / Linux:**
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
3. Установите необходимые библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите веб-сервер, привязав его к хосту `0.0.0.0` (это обязательно, чтобы Android-эмулятор мог достучаться до сервера):
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```
5. Проверьте работоспособность, перейдя в браузере по адресу:
   * Базовая страница: `http://127.0.0.1:8000/`
   * Интерактивная документация: `http://127.0.0.1:8000/docs` (при первом запуске FastAPI автоматически создаст таблицы `users` и `podcasts` в вашей MySQL-базе).

### Шаг 3: Настройка и запуск мобильного приложения (Flutter)

1. Откройте новый терминал и перейдите в папку с вашим Flutter-проектом:
   ```bash
   cd client
   ```
2. Убедитесь, что в файле **`android/app/src/main/AndroidManifest.xml`** внутри тега `<application ...>` прописана строчка разрешения HTTP-трафика (без нее на Android-устройствах не будет работать аудио-плеер и сетевые запросы):
   ```xml
   android:usesCleartextTraffic="true"
   ```
3. Проверьте, что в файле **`lib/services/api_service.dart`** правильно указан адрес сервера. По умолчанию в коде настроено:
   * `http://10.0.2.2:8000` для эмулятора Android.
   * `http://localhost:8000` для симулятора iOS, Web или Desktop.
4. Выполните загрузку библиотек:
   ```bash
   flutter pub get
   ```
5. Запустите эмулятор смартфона (или подключите реальное устройство по USB) и запустите сборку приложения:
   ```bash
   flutter run
   ```

### Дополнительно: Как протестировать панель администратора

Для публикации новых аудиофайлов и удаления контента вам понадобится аккаунт с правами администратора:

1. Запустите мобильное приложение на телефоне/эмуляторе.
2. Перейдите на страницу регистрации (ссылка под формой входа) и зарегистрируйте нового пользователя, например: `admin@test.com`.
3. Откройте ваш клиент управления базой данных MySQL (или консоль) и выполните SQL-запрос, чтобы назначить этому пользователю роль администратора:
   ```sql
   UPDATE users SET role = 'admin' WHERE email = 'admin@test.com';
   ```
4. Вернитесь в приложение, перейдите на экран входа и авторизуйтесь под этим email. 
5. Приложение автоматически распознает роль и откроет **Панель администратора**, где вы сможете загружать новые файлы `.mp3` прямо из памяти телефона и управлять каталогом. Любой зарегистрированный после этого обычный пользователь сразу увидит новые подкасты на своём главном экране.
